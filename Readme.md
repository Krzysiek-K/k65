# K65 - Custom Assembler for 6502-based CPUs

K65 is a compiler/assembler-oriented language and toolchain for 6502-family platforms, with practical support for **Atari 8-bit** (400/800/XL/XE), **Commodore 64**, and **Atari 2600/VCS** projects.

Use this README for quick setup, and [doc/docs/index.md](doc/docs/index.md) as the full documentation hub.

## Quick Start

Build from the project root:

```bash
make
```

Run tests:

```bash
make test
```

Expected result: test output ends with `All OK`.
